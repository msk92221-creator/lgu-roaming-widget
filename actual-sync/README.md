# U+ 로밍 실제값 위젯 2.0 beta

Galaxy Z Fold7 홈 화면에 **U+one의 ‘해외 로밍 이용 현황’ 화면에서 읽은 실제 표시값**을 보여 주는 개인용 Android 위젯입니다.

이 버전은 Android 사용량을 빼서 잔여량을 추정하지 않습니다. 직접 입력한 수치도 사용하지 않습니다.

## beta1 확인 순서

1. APK를 기존 1.0 앱 위에 설치합니다. 같은 앱 ID와 서명 키를 사용하므로 업데이트 설치됩니다.
2. 앱 정보의 오른쪽 위 `⋮`에서 **제한된 설정 허용**을 누릅니다. 이 메뉴가 없으면 다음 단계로 갑니다.
3. 앱에서 **접근성 설정 열기**를 누르고 `U+one 로밍 실제값 읽기`를 켭니다.
4. **U+one 열고 동기화**를 누릅니다.
5. U+one에서 `해외 로밍 → 이용 현황`을 엽니다.
6. 화면에 표시된 로밍 데이터 값이 감지되면 위젯 값이 갱신됩니다.

감지되지 않으면 이 앱으로 돌아와 **기기 확인용 정보 → 진단 정보 복사**를 누른 뒤 그 내용을 개발 작업에 전달해 주세요. 전화번호·계정·비밀번호는 진단 정보에 저장하지 않습니다.

## 정확성 원칙

- `남은 데이터 6.5GB`처럼 U+one이 잔여량을 직접 표시할 때만 `6.5GB 남음`으로 저장합니다.
- U+one이 `사용량`과 `제공량`만 표시하면 이를 진단 상태로 남기고 잔여량을 뺄셈으로 만들지 않습니다.
- 국내 데이터 `무제한`, 상품명 속 용량, 소진 후 속도, 날짜·요금 숫자는 거부합니다.
- 서로 다른 로밍 계량기가 여러 개면 임의로 고르지 않고 진단 상태로 남깁니다.
- 기존 1.0의 기기 추정값은 업데이트 후 폐기합니다.

## Android상 한계

LG U+가 개인 고객용 공개 API를 제공하지 않으므로 U+one이 닫힌 상태에서 원장값을 조회할 수는 없습니다. 위젯을 누른 뒤 U+one의 로밍 이용 현황 화면이 실제로 열려 있을 때만 동기화합니다.

beta1은 U+one이 등록한 `해외 로밍 이용 현황` 딥링크를 대상 패키지에 한정해 엽니다. 구형 U+one에서 딥링크를 처리하지 못하면 앱 첫 화면을 열며, 이 경우 이용 현황 화면으로 직접 이동해야 합니다. Fold7의 실제 접근성 구조가 확인되기 전에는 읽을 수 없는 값을 추측하지 않고 진단 상태로 남깁니다.

## 권한과 개인정보

- 접근성 서비스 대상 패키지는 `com.lguplus.mobile.cs` 하나로 제한됩니다.
- `INTERNET`, 위치, 연락처, 전화, SMS, 사용정보 접근 권한이 없습니다.
- 읽은 표시값과 확인 시각은 앱 전용 저장소에만 보관합니다.
- 앱은 LG U+가 제공하거나 보증한 공식 앱이 아닙니다.

자세한 내용은 [PRIVACY.md](PRIVACY.md)를 확인하세요.

## 빌드

필요 환경은 JDK 17과 Android SDK 35입니다.

```text
./gradlew -p actual-sync test lint assembleRelease
```
