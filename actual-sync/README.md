# U+ 로밍 실제값 위젯 3.0 beta

LG U+ 공식 웹의 로밍 표시값을 홈 화면에 보여 주는 개인용 Android 위젯입니다. U+one 전면 화면을 읽던 2.x 대신 자체 로그인 세션으로 무화면 웹 조회를 구현합니다. 1.x 추정 버전과 2.x 접근성 버전은 앱을 열지 않는 새로고침 요구를 충족하지 못했습니다.

## 개발·검증 상태

`3.0.0-beta3` / versionCode `9`은 실기기 확인용 베타입니다. Java 단위·구조 테스트 70개, 실제 JS 추출 모듈의 DOM 테스트 68개와 lint(오류 0개), APK 빌드를 확인했습니다. PC의 정상 로그인 브라우저에서 공식 총 데이터 조회·세션 유지와 사용자의 모바일 WebView 화면에서 로그인·실제 수치 표시를 확인했지만, 모바일 연결 완료와 앱 종료 후 위젯 갱신은 아직 검증 전입니다.

[테스트 APK 다운로드](https://github.com/msk92221-creator/lgu-roaming-widget/releases/download/v3.0.0-beta3/lgu-roaming-widget-v3.0.0-beta3.apk)

beta3는 공식 모바일 번들 `cbad2c9403710139e15d4c01000289e1c0aa0812`의 `281_f10ba86c93c38669f1af.js`에서 확인한 `.roaming-info__item--data`의 직접 자식 `.roaming-info__label`과 `.roaming-info__value`만 읽습니다. 이 항목의 `.roaming-info__data`에는 기본·충전·테더링 수치가 중첩돼 있으므로 부모 전체 텍스트로 대체하지 않습니다. 동일 구조 fixture로 beta2의 5개 실패를 먼저 재현했습니다. 모바일 API 경로는 기존과 같은 GET임을 소스에서 확인했습니다. 실제 폰의 응답 완료·백그라운드 동작까지 검증된 것은 아니며 완료 검사는 그대로 유지합니다.

## 기기 확인 순서

1. APK를 설치한 뒤 이 앱에서 **공식 웹 로그인 / 재로그인**을 누릅니다.
2. 자체 WebView의 공식 LG U+ 웹에 직접 로그인합니다. PC·Chrome·U+one의 로그인 쿠키를 가져오는 기능은 없습니다.
3. 로그인 뒤 홈으로 가면 상단 **로밍 조회로 이동**을 누릅니다. 총 데이터가 감지되어 **연결 완료**가 표시되는지 확인합니다.
4. 기존 위젯은 삭제 후 다시 추가하고 앱을 닫은 상태에서 위젯의 **새로고침**을 누릅니다.
5. 실제 표시값·확인 시각과 실패 상태를 확인합니다. 이 경로에서 U+one이나 로그인 Activity가 자동 실행되면 정상 동작이 아닙니다.

세션 만료 시 이전 정상 수치·확인 시각을 보존하고 재로그인 필요 상태를 표시합니다. 사용자가 직접 앱을 열어 재로그인해야 하며 영구 로그인은 보장하지 않습니다. 비밀번호·인증번호·쿠키·토큰을 채팅이나 이슈에 보내지 마세요.

## 구현 경계

- 공식 페이지: `https://www.lguplus.com/plan/roaming/my-roaming`
- 자체 WebView가 정상 웹 요청을 실행합니다. 읽기 전용 `GET /uhdc/fo/myin/roam/v1/data-rmndlist` 완료 여부 확인 후 총 데이터의 제한된 DOM 선택자만 읽습니다. API 응답을 별도 HTTP 클라이언트로 전달하거나 인증값을 추출하지 않습니다.
- 위젯 새로고침은 명시적 내부 브로드캐스트에서 작업을 예약합니다. `JobService`의 메인 스레드에서 비표시 WebView를 사용하고 성공·실패·시간 초과 시 정리합니다.
- `JobScheduler` 우선 처리 작업을 사용할 수 없으면 일반 작업으로 대체합니다. 네트워크·시스템 부하·할당량에 따라 지연될 수 있어 즉시 완료를 보장하지 않습니다.
- 단발성 조회이며 지속적인 실시간 연결이나 상시 폴링은 아닙니다.
- 접근성 서비스·U+one 패키지 조회·U+one 자동 실행을 사용하지 않습니다. Cloudflare·CAPTCHA·인증·TLS 검증을 우회하지 않습니다.

## 값 처리

공식 총 데이터 영역에서 남은량과 전체량이 명확하게 연결될 때만 저장합니다. 사용량은 같은 계량기의 전체량−남은량이며 통신사 반올림 정밀도를 따릅니다. 기기 통계·수동 수치·상품명 용량·국내 무제한 데이터를 대체 자료로 사용하지 않습니다.

지원하지 않는 DOM 구조, 무제한·소진 전용 표기, 여러 계량기 또는 인증 상태가 불명확하면 임의 선택하지 않고 실패로 처리합니다. 실패 시 이전 정상 값·확인 시각을 유지합니다. 확인 시각은 이 앱의 조회 시각이지 통신사 원장 집계 시각이 아니며 통신사 집계 지연을 없애거나 보증할 수는 없습니다.

## 화면과 저장소

4×1 가로형 흰 카드에 분홍→보라색 잔여량 막대, 남은량, 사용량, 새로고침 버튼, 최근 확인 상태를 표시합니다. 막대는 남은량÷전체량입니다. Fold7 커버·메인 화면마다 위젯을 따로 추가할 수 있습니다.

로그인 상태는 자체 WebView 쿠키·웹 저장소에 남으며 PC 브라우저와 공유되지 않습니다. 앱 코드는 비밀번호·인증번호·쿠키·토큰을 직접 읽지 않습니다. 조회값·시각·비밀값 없는 오류 분류는 앱 전용 저장소에 보관합니다. WebView 데이터를 포함한 앱 데이터는 백업·기기 이전에서 제외하도록 설정합니다.

`INTERNET`과 `ACCESS_NETWORK_STATE`를 사용합니다. 개발자 서버·분석 SDK는 없지만 공식 웹 및 소셜 로그인 제공자는 정상 웹 동작에 필요한 외부 리소스를 로드할 수 있습니다. 자세한 내용은 [개인정보 안내](PRIVACY.md)를 확인하세요.

## 빌드와 테스트

JDK 17과 Android SDK 35가 필요합니다.

```text
./gradlew -p actual-sync test lint assembleRelease
```

Windows PowerShell:

```powershell
.\gradlew.bat -p actual-sync test lint assembleRelease
```

실제 APK에 들어가는 JavaScript DOM 추출 모듈의 테스트:

```text
cd actual-sync/js-tests
npm ci --ignore-scripts
npm test
```

단위 테스트·lint·APK 빌드와 별도로, 실기기에서 최초 로그인, 앱 종료, 프로세스 재시작 후 갱신, 세션 만료, 네트워크 실패, 통신사 화면 변경을 확인해야 합니다. LG U+가 제공하거나 보증한 공식 앱이 아닙니다.
