# 개인정보 안내 — 3.0 웹 조회 시험 버전

이 앱은 LG U+ 공식 웹의 로밍 총 데이터 표시값을 조회하는 개인용 비공식 위젯입니다. 개발자 계정·서버·분석 SDK는 없습니다. 인터넷 조회를 위해 `INTERNET`과 `ACCESS_NETWORK_STATE` 권한을 사용합니다.

## 로그인 세션

사용자가 이 앱 안에 열린 공식 웹 로그인 화면에 직접 로그인합니다. 비밀번호·인증번호는 LG U+ 또는 사용자가 선택한 로그인 제공자의 정상 웹 흐름으로 처리됩니다. 앱 코드는 비밀번호·인증번호·쿠키·토큰을 직접 읽거나 개발자에게 전송하지 않습니다.

**자체 WebView는 쿠키·로컬 저장소 등 로그인 세션을 기기에 보관합니다.** 인증 정보를 전혀 저장하지 않는다는 뜻이 아닙니다. PC·다른 브라우저·U+one의 쿠키를 복사하지 않으므로 이 앱에서 최초 로그인이 별도로 필요합니다. 로그인 만료·재인증 주기는 제공자가 결정하며 영구 유지나 만료 우회를 제공하지 않습니다.

## 로밍 조회와 앱 저장값

자체 WebView는 `https://www.lguplus.com/plan/roaming/my-roaming`을 정상 로드합니다. 사이트의 읽기 전용 `GET /uhdc/fo/myin/roam/v1/data-rmndlist` 완료 여부 확인 후 총 데이터 영역의 제한된 DOM 선택자에서만 수치를 읽습니다. 인증값 추출이나 별도 HTTP 요청 재전송은 하지 않습니다.

앱 전용 저장소에는 잔여량·전체량, 두 표시값의 차액인 사용량, 확인 시각, 로그인 설정 여부, 조회 상태와 비밀값 없는 오류 분류를 보관합니다. 전체 HTML·전화번호·고객명·비밀번호·인증번호·쿠키·토큰은 진단에 포함하지 않습니다.

인식 실패 시 공개된 LG U+ 1차 스크립트 파일 참조를 최대 12개 진단에 포함할 수 있습니다. 공식 HTTPS 호스트의 정적 JS 경로만 허용하고 쿼리·프래그먼트는 제외합니다. 이는 쿠키나 인증 요청 URL이 아닌 공개 웹 빌드 구조를 확인하기 위한 정보입니다.

WebView의 정상 쿠키·캐시·웹 저장소는 앱 조회값과 별도로 존재하며 공식 사이트가 저장한 정보를 포함할 수 있습니다. 조회 실패 시 기존 정상 수치·확인 시각을 유지합니다. 새로고침은 단발성이며 U+one이나 로그인 화면을 자동 실행하지 않습니다.

## 네트워크와 제공자 정책

정상 웹 조회·로그인 요청은 LG U+와 선택한 로그인 제공자에 전달됩니다. 공식 사이트가 외부 리소스나 추적 도구를 로드할 수 있으며 그 처리는 해당 제공자의 정책을 따릅니다. 개발자 분석 SDK가 없다는 것이 공식 웹의 외부 통신까지 없다는 뜻은 아닙니다.

Cloudflare·CAPTCHA·인증·TLS 인증서 검증을 우회하지 않습니다. 접근성 서비스·U+one 앱 조회·위치·연락처·전화·SMS·사용정보 접근 권한은 사용하지 않습니다.

## 보관과 삭제

앱 조회값과 자체 WebView 세션은 이 앱의 전용 기기 저장소에 보관되며 개발자 서버에 업로드하지 않습니다. WebView 데이터를 포함한 앱 데이터를 Android 백업·기기 이전에서 제외하도록 설정하고 `allowBackup`을 비활성화합니다.

Android 설정에서 이 앱의 저장공간 데이터를 삭제하거나 앱을 제거하면 저장값과 자체 WebView 세션을 지울 수 있습니다. 다른 브라우저나 U+one의 세션은 삭제하지 않습니다. 이후에는 이 앱에서 다시 로그인해야 합니다.

LG U+와 제휴·승인·보증 관계가 없는 개인용 시험 버전입니다. PC 정상 로그인 웹 조회는 확인했지만 Android 실기기 전체 동작 검증은 아직 완료되지 않았습니다.
