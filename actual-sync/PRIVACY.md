# 개인정보 안내 — 실제값 동기화 beta

이 앱은 계정을 만들지 않고 개발자 서버를 운영하지 않으며 `INTERNET` 권한도 요청하지 않습니다.

## 접근성 서비스가 읽는 범위

Android 접근성 서비스 설정에서 대상 앱을 U+one 패키지 `com.lguplus.mobile.cs`로 제한했습니다. 사용자가 이 앱의 동기화 버튼이나 위젯을 누른 뒤 U+one을 전면에 열어 둔 짧은 동기화 세션에만 화면 텍스트를 검사합니다.

검사 목적은 `해외 로밍 이용 현황` 화면인지 확인하고 그 화면이 직접 표시한 잔여량 문구를 찾는 것입니다. 사용량·제공량만 보이면 계산하지 않고 진단 상태로 남깁니다. 앱은 버튼을 자동 클릭하거나 아이디·비밀번호를 입력하지 않습니다.

## 기기에 저장하는 정보

- U+one 로밍 화면에서 읽은 데이터 표시 문자열
- 값의 유형과 확인 시각
- 인식 실패 시 로밍·데이터·사용량과 관련된 제한된 진단 문구

전화번호와 이메일 형식은 진단 문구에서 마스킹합니다. 전체 접근성 화면 트리, U+ 아이디, 비밀번호, 인증번호, 쿠키는 저장하거나 전송하지 않습니다.

정보는 앱의 비공개 `SharedPreferences`에만 저장되고 Android 백업은 비활성화됩니다. 앱을 삭제하면 함께 삭제됩니다.

## 비공식 앱

이 프로젝트는 LG U+와 제휴·승인 관계가 없는 개인용 비공식 앱입니다.
