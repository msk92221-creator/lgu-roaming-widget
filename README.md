# LG U+ 로밍 실제값 위젯

Galaxy Z Fold7 홈 화면에서 **U+one의 ‘해외 로밍 이용 현황’에 실제로 표시된 값**을 보는 개인용 Android 위젯입니다.

> 기존 `v1.0.0`은 휴대폰 통계로 잔여량을 추정한 버전이라 요구사항과 달랐습니다. 사용하지 마세요. `v2.0.0-beta1`부터 추정·수동 입력을 모두 제거했습니다.

## beta APK 설치

[v2.0.0-beta3 APK 바로 받기](https://github.com/msk92221-creator/lgu-roaming-widget/releases/download/v2.0.0-beta3/lgu-roaming-widget-v2.0.0-beta3.apk)

기존 1.0이 설치돼 있으면 같은 서명 키의 업데이트로 설치됩니다.

1. APK를 설치합니다.
2. 앱 정보 오른쪽 위 `⋮`에 **제한된 설정 허용**이 보이면 누릅니다.
3. 앱에서 **접근성 설정 열기**를 누르고 `U+one 로밍 실제값 읽기`를 켭니다.
4. **U+one 열고 동기화**를 누릅니다.
5. 앱이 U+one의 `해외 로밍 이용 현황` 화면을 공식 딥링크로 열고, 표시된 잔여량 원문을 감지하면 위젯을 갱신합니다.
6. 감지되지 않으면 앱의 **기기 확인용 정보 → 진단 정보 복사** 결과를 이 개발 작업에 보내 주세요.

beta3는 U+one의 `총 데이터` 행을 화면 좌표로 식별합니다. `기본 데이터` 등 구성 항목이 별도로 표시돼도 전체 잔여량을 선택하며, 여러 회선의 총 데이터 행이 있거나 연결 근거가 없으면 실패 상태로 남깁니다.

위젯은 기본 4×2 가로형으로 사용량과 남은량을 나란히 표시합니다. 남은량과 전체량은 U+one 표시 원문이고, 사용량은 이 두 표시값의 차액입니다. 예를 들어 `47.8GB남음 / 49GB`는 남은량 `47.8 GB`, 사용량(차액) `1.2 GB`로 표시합니다. U+one의 반올림 단위를 따릅니다.

## 작동 원칙

- `남은 데이터 6.5GB`처럼 U+one이 직접 표시한 잔여량만 `6.5GB 남음`으로 저장합니다.
- 국내 데이터 `무제한`, 상품명 속 용량, 소진 후 속도, 요금·날짜 숫자는 거부합니다.
- `6GB 500MB`처럼 구조 확인이 필요한 복합 표기나 여러 계량기가 있으면 임의로 고르지 않습니다.
- 사용량과 제공량만 보일 때는 둘을 빼서 잔여량을 만들지 않습니다. 사용량(차액)은 같은 `총 데이터` 행의 전체량−남은량으로 계산합니다.
- 기존 v1의 추정값은 업데이트 후 폐기됩니다.

## 왜 완전 백그라운드 동기화가 아닌가

최신 U+one 앱을 분석한 결과:

- 개인 고객용 로밍 잔여량 공개 API가 없습니다.
- U+one 자체 위젯 권한은 LG U+ 서명 앱만 쓸 수 있는 `signature` 권한입니다.
- 로밍 이용 현황으로 바로 가는 공식 앱 딥링크는 있지만, 값 자체를 외부 앱에 반환하지는 않습니다.

따라서 정확한 원장값을 쓰려면 위젯을 누른 뒤 U+one 화면이 실제로 열린 순간 접근성 서비스가 표시 원문을 읽어야 합니다. 닫힌 U+one에서 값을 몰래 주기 조회하는 기능은 약속하지 않습니다.

## 권한·개인정보

- 접근성 서비스 대상은 U+one 패키지 `com.lguplus.mobile.cs` 하나입니다.
- 동기화 버튼/위젯을 누른 뒤 최대 10분의 세션에서만 읽습니다.
- 비밀번호 필드는 읽지 않고, 로밍 화면이 아닌 곳의 원문은 저장하지 않습니다.
- `INTERNET`, 위치, 연락처, 전화, SMS, 사용정보 접근 권한이 없습니다.
- 값과 확인 시각은 앱 전용 저장소에만 보관하며 백업·기기 이전에서 제외합니다.

자세한 내용은 [PRIVACY.md](PRIVACY.md)를 확인하세요.

## 소스와 빌드

실제값 버전 소스는 [`actual-sync`](actual-sync) 폴더에 있습니다.

```text
./gradlew -p actual-sync test lint assembleRelease
```

필요 환경은 JDK 17과 Android SDK 35입니다. APK는 고정 릴리스 인증서로 서명하고 `apksigner verify`를 통과한 뒤 배포합니다.
