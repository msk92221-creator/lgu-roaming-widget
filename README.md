# LG U+ 로밍 데이터 위젯

Galaxy Z Fold7을 포함한 Android 홈 화면에서 **LG U+ 로밍 데이터 잔여량을 추정해 보여 주는 비공식 개인용 위젯**입니다.

> 이 앱은 LG U+가 제공하거나 보증한 앱이 아닙니다. 통신사 과금 원장의 실시간 수치가 아니라, 사용자가 입력한 U+ 공식 잔여량에서 이 휴대폰이 측정한 이후 로밍 모바일 사용량을 차감한 추정값입니다.

## APK 설치

1. GitHub의 [최신 Release](../../releases/latest)에서 `lgu-roaming-widget-v1.0.0.apk`를 받습니다.
2. 휴대폰에서 APK를 열고, 요청되면 해당 브라우저/파일 앱의 **알 수 없는 앱 설치**를 허용합니다.
3. 앱을 열어 **U+ 로밍 이용 현황**에서 확인한 상품 제공량과 현재 잔여량을 입력합니다.
4. **사용정보 접근 설정 열기**를 눌러 `로밍 잔여량 위젯`을 허용합니다.
5. Galaxy 홈 화면을 길게 눌러 **위젯 → 로밍 잔여량 위젯**을 추가합니다.

Android 15 이상에서 사용정보 접근 스위치가 비활성화되면, 앱의 **앱 정보 → 오른쪽 위 ⋮ → 제한된 설정 허용**을 누른 뒤 다시 시도하세요.

## 작동 방식

- 사용자가 [LG U+ 공식 로밍 이용 현황](https://www.lguplus.com/plan/roaming/my-roaming)의 현재 값을 한 번 입력합니다.
- Android `NetworkStatsManager`에서 그 시점 이후 이 휴대폰의 `ROAMING_YES` 모바일 송수신량을 읽습니다.
- 마지막 추정 잔여량에서 새로 증가한 사용량만 차감합니다. Android 통계가 초기화되어도 잔여량이 다시 늘어나지 않도록 재기준화합니다.
- 30분 주기와 사용자의 새로고침 동작으로 표시를 갱신합니다.
- Fold7의 작은 2×1, 기본 3×2, 넓은 가로형 크기에 맞춰 레이아웃이 바뀝니다.

## 알아둘 점

- LG U+ 개인 고객용 공개 API가 없어 자동으로 통신사 원장을 동기화하지 않습니다. 로그인 화면 스크래핑이나 비공개 API 호출도 하지 않습니다.
- 테더링, 나눠쓰기, 다른 기기 사용, 듀얼 로밍 SIM, 업무 프로필 사용량, 통신사 집계 지연 때문에 U+ 표시와 차이가 날 수 있습니다.
- 차이가 생기면 앱에서 U+ 공식 잔여량을 다시 입력해 보정하면 됩니다.
- `INTERNET` 권한이 없으며 입력값과 사용량은 기기에만 저장됩니다. Android 백업도 비활성화했습니다.

## 권한

- `PACKAGE_USAGE_STATS`: Android가 기록한 로밍 모바일 사용량 조회. 사용자가 설정 화면에서 직접 허용해야 합니다.
- `RECEIVE_BOOT_COMPLETED`: 재부팅 후 주기 갱신 예약 복원.

네트워크 접속 권한, 위치, 연락처, 전화, SMS 권한은 사용하지 않습니다.

## 직접 빌드

필요 환경: JDK 17, Android SDK 35.

```text
./gradlew test lint assembleRelease
```

Gradle Wrapper 배포 ZIP은 SHA-256으로 고정 검증합니다. GitHub Actions는 테스트·린트·서명되지 않은 release 빌드까지만 수행하며 APK를 배포하지 않습니다. 실제 Release APK는 고정된 로컬 릴리스 키로 별도 서명하고 `apksigner verify`를 통과한 파일입니다.
