# LG U+ 로밍 실제값 위젯

Galaxy Z Fold7에서 LG U+ 공식 웹의 로밍 잔여량·전체량을 확인하는 개인용 비공식 Android 위젯입니다. 목표는 **U+one 앱을 띄우지 않고 위젯의 새로고침 버튼으로 조회**하는 것입니다. 국내 데이터 통계나 수동 입력값으로 잔여량을 추정하지 않습니다.

## 현재 상태

`v3.0.0-beta2` / versionCode `8`은 **실기기 확인용 베타**입니다. Java 단위·구조 테스트 70개, 실제 추출 JavaScript의 DOM 회귀 테스트 55개와 lint(오류 0개), APK 빌드 검사를 통과했습니다. 실제 Android 기기에서 앱을 닫은 뒤 위젯 갱신까지의 종단 간 동작은 검증 전입니다.

[v3.0.0-beta2 테스트 APK 다운로드](https://github.com/msk92221-creator/lgu-roaming-widget/releases/download/v3.0.0-beta2/lgu-roaming-widget-v3.0.0-beta2.apk)

beta1은 PC용 DOM 선택자만 사용해 모바일 웹에서 로그인과 실제 수치가 보여도 연결을 완료하지 못했습니다. beta2는 모바일의 정확한 `총 데이터 43.9GB남음 / 49GB` 형태를 최소 부모 행에서 읽고, 기본 데이터·충전 홍보·복수 계량기를 제외합니다. 폰에서 사용되는 조회 API의 완료 확인까지 통과하는지는 아직 확인 전이며, 이 검사를 임의로 완화하지 않았습니다. 실패 단계와 비밀값 없는 공개 스크립트 참조를 진단에 남겨 원인을 구분합니다.

정상 로그인한 PC 브라우저에서 [LG U+ 공식 해외 로밍 이용 현황](https://www.lguplus.com/plan/roaming/my-roaming)의 정량 요금제 총 데이터 표시와 페이지 새로고침 후 세션 유지를 확인했습니다. 이는 폰의 WebView에서도 동일하게 동작한다는 보증은 아닙니다.

기존 `v1.0.0`은 기기 통계에 의한 추정 방식이고, `v2.0.0-beta1`부터 `beta5`까지는 U+one 전면 화면을 접근성으로 읽는 방식입니다. 두 방식 모두 **앱을 열지 않는 위젯 새로고침** 요구를 충족하지 못합니다. 새 버전 대신 이전 APK를 설치하도록 안내하지 않습니다.

## 새 버전의 사용 흐름

다음 순서로 기기 확인이 필요합니다. 기존 APK 위에 같은 서명의 업데이트로 설치할 수 있습니다.

1. 새 APK를 설치하고 이 앱을 엽니다.
2. **공식 웹 로그인 / 재로그인**을 눌러 이 앱의 WebView 안에서 공식 LG U+ 웹에 직접 로그인합니다. PC나 다른 브라우저의 쿠키는 복사하지 않습니다.
3. 로그인 뒤 홈으로 이동했다면 상단 **로밍 조회로 이동**을 누릅니다. 실제 총 데이터가 감지되어 **연결 완료**가 뜨는지 확인합니다.
4. 기존 위젯은 삭제 후 다시 추가하고 앱을 닫습니다.
5. 위젯의 **새로고침**을 누릅니다. 정상 조회 경로는 U+one이나 이 앱의 Activity를 실행하지 않습니다.

로그인이 만료되면 위젯에 재로그인 필요 상태를 표시합니다. 자동으로 로그인 화면이나 U+one을 띄우지 않으며, 사용자가 직접 이 앱을 열어 재로그인해야 합니다. 최초 로그인 한 번으로 영구 유지된다고 약속하지 않습니다.

## 조회 방식과 정확성

- 자체 WebView가 공식 페이지를 정상 로드합니다. 사이트가 실행하는 읽기 전용 `GET /uhdc/fo/myin/roam/v1/data-rmndlist` 요청 완료 여부를 확인하고, 로밍 **총 데이터** 영역의 제한된 DOM 선택자에서 표시값을 읽습니다.
- API 응답을 별도 HTTP 클라이언트로 전달하거나 쿠키·토큰을 추출하지 않습니다. Cloudflare·CAPTCHA·인증·TLS 검증을 우회하지 않습니다.
- 남은량과 전체량은 공식 웹 표시값입니다. 사용량은 같은 계량기의 `전체량 − 남은량`이며 통신사 표시의 반올림 정밀도를 따릅니다.
- 현재 확인 사례는 49GB 정량 요금제입니다. 다른 요금제·국내 무제한 데이터·상품명 용량·소진 전용 화면·여러 계량기·지원하지 않는 DOM 구조를 임의로 해석하거나 추정하지 않습니다. 인식 실패 시 실패 상태로 남깁니다.
- 실패 시 이전 정상 수치와 확인 시각을 유지합니다. 이전 값 재표시를 새 조회 성공으로 처리하지 않습니다.
- 표시 시각은 이 앱이 웹 표시값을 확인한 시각입니다. 통신사 원장 집계 시각이나 집계 지연이 없음을 보장하지 않습니다.

새로고침은 단발성 조회이며 지속적인 실시간 연결이나 상시 폴링이 아닙니다. `JobScheduler` 우선 처리 작업을 요청하고 사용할 수 없으면 일반 작업으로 대체하므로 기기 상태·작업 할당량·네트워크에 따라 시작이 지연될 수 있습니다.

## 위젯

기본 4×1 가로형입니다. 흰색 둥근 카드에 분홍→보라색 잔여량 막대, 남은량, 사용량, 새로고침 버튼과 마지막 확인 상태를 표시합니다. 막대는 남은량÷전체량 비율이며 확인하지 못한 값을 채워 넣지 않습니다. 폴드의 커버 화면과 메인 화면에는 각각 위젯 추가가 필요할 수 있습니다.

## 권한·개인정보

`INTERNET`과 `ACCESS_NETWORK_STATE`를 사용합니다. 접근성 서비스·U+ 앱 조회·사용정보 접근 권한은 사용하지 않습니다. 개발자 서버나 분석 SDK는 없습니다. 공식 웹과 로그인 제공자가 로드하는 외부 리소스의 통신과 정보 처리는 해당 제공자의 정책을 따릅니다.

로그인 세션은 자체 WebView 쿠키·웹 저장소에 보관합니다. 앱 코드는 비밀번호·인증번호·쿠키·토큰을 직접 읽거나 개발자에게 전송하지 않습니다. 조회값과 확인 시각은 앱 전용 저장소에 보관하고, WebView 데이터를 포함한 앱 데이터를 백업·기기 이전에서 제외하도록 설정합니다. 자세한 내용은 [개인정보 안내](PRIVACY.md)를 확인하세요.

## 소스와 빌드

새 버전 소스는 [`actual-sync`](actual-sync)입니다. JDK 17과 Android SDK 35가 필요합니다.

```text
./gradlew -p actual-sync test lint assembleRelease
```

Windows PowerShell:

```powershell
.\gradlew.bat -p actual-sync test lint assembleRelease
```

릴리스 APK는 기존 릴리스 인증서로 서명하고 서명을 검증한 뒤 배포해야 합니다. 빌드 성공만으로 실제 통신사 계정의 Android 무화면 조회 검증이 끝나는 것은 아닙니다.

이 프로젝트는 LG U+와 제휴·승인·보증 관계가 없는 개인용 비공식 앱입니다.
